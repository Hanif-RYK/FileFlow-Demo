# FileFlow – Live Demo

Live demo of **FileFlow**, a multi-company document, checkout and task management web app.

**Open the demo:** https://hanif-ryk.github.io/FileFlow-Demo/

- Runs on sample data in your browser; nothing is saved and everything resets on reload.
- Use **View as** at the bottom to switch between Admin, Staff and Viewer.

The full product (database setup, security rules and documentation) is available to buyers.
